# Nikonect 0.3.0

包名 dev.nikonect，versionCode 4。可覆盖安装 0.2.1，保留应用设置和照片。

## 本版功能

- 参数自动同步：普通模式约 900ms、监看约 1800ms 回读；每约 5 秒重读属性描述，更新模式可写性和镜头报告范围。操作、照片下载或相机忙时会推迟，以上为轮询间隔，不是保证的同步延迟。
- 优先使用 GetDevicePropValue 的实际值，而非只显示 GetDevicePropDesc 内可能滞后的 CurrentValue。调节前重新读取描述与实际值，写后有限重试确认，显示相机实际接受的结果。
- ISO、快门、光圈按相机提供的枚举或范围调节；枚举按数值排序，到边界停止，不再从最大值回绕到最小值。边界按钮禁用。范围不合法时禁用调整，不硬编码某支镜头的光圈范围。
- 相册支持“多选”或长按进入选择，跨分页选择、全选、系统批量分享、确认后删除；单张查看支持分享和确认删除。删除限于 Nikonect 拥有的已接收 JPG，不发送相机删图命令。NEF 不受 JPG 相册删除影响。
- 监看去掉参数侧栏，在整幅预览上叠加快门、光圈、ISO、曝光补偿，以及相机公布的曝光模式、白平衡、电量。点曝光参数打开调节框。未读到的数据显示“—”；回读过期或失败时标示“参数待同步”。
- 监看顶部只提供参数、相册、设置；可隐藏并通过右上角按钮恢复。网格、直方图和拍摄操作保留，信息叠加也可单独隐藏。
- 系统返回按页面打开历史回退；相册先关闭单张查看或退出多选，再返回前一个页面。各页的可保存界面状态保留。
- 新增实验性 Wi-Fi PTP/IP：独立命令/数据和事件 TCP 连接、持久客户端 GUID、事件心跳响应、事务校验、分块传图。Socket 绑定选定 Wi-Fi 网络，不依赖手机默认移动数据路由。与 USB 共用参数、拍摄、传图和预览控制逻辑。

## 无线使用步骤

1. 拔下 USB 或先在 App 断开现有会话。退出 SnapBridge 等可能占用相机的应用。
2. Z50：设定菜单 → 连接至智能设备 → Wi-Fi 连接 → 建立 Wi-Fi 连接；相机会显示 SSID 和密码。
3. 参数页点 Wi-Fi 图标，打开系统 Wi-Fi 设置，连接该热点。手机询问时选择保留无互联网连接。
4. 回 Nikonect，核对相机 IPv4 地址。可点“使用网关”填入当前 Wi-Fi 默认网关；若热点网关不是相机服务地址，需改成实际地址。默认端口 15740。
5. 点连接。成功后尝试读取参数、拍摄；默认自动接收本次会话建立后新增的 JPG。开启 NEF 时也接收新 NEF。
6. 相机服务未开放、拒绝握手、超时或需要额外认证时会显示失败阶段；在设置 → 诊断导出日志以便进一步适配。

这不是自动蓝牙配对或 SnapBridge 克隆。未实现 Wi-Fi 自动发现、蓝牙唤醒、Nikon 私有无线认证或“连接至 PC”配对流程。没有 Z50 真机无线实测，不能把本版标为已验证无线兼容。相机固件/模式是否提供标准 PTP/IP，以及是否开放各项操作，仍需现场确认。

## 相机屏幕元素的边界

当前是 JPEG 实时预览加 App 绘制的信息层，不是相机 LCD 的屏幕镜像。能够显示相机通过已支持标量属性公布的曝光参数、模式、白平衡和电池信息；未公布的值留空。相机完整菜单、对焦/人眼识别框、电子水平仪、原机所有状态图标尚未解析或复现。直方图是 App 根据 JPEG 计算的亮度分布。

自动 ISO 下标准 ISO 属性可能是设置值，而不是每帧曝光实际 ISO；本版不把它标为实测逐帧 ISO。取景帧中的 Nikon 元数据还需型号与固件对应的抓包核实。没有伪造对焦框或水平仪。

## 待 Z50 真机确认

- 更换镜头、变焦、转动相机拨轮以及 M/A/S/P 模式切换时，标准光圈描述 0x5007 是否及时收窄到当前镜头范围。App 按相机报告限制并以回读为准；若固件报告范围本身过宽，仍可能被相机拒绝或钳制，需导出含范围的诊断进一步适配。
- GetDevicePropValue 0x1015 在 USB/无线的具体行为和回读时机。
- Nikon 取景 0x9201/0x9202/0x9203 在 Wi-Fi 会话中的支持情况；只在相机声明支持时默认使用，实验开关可允许尝试。
- 拍摄优先用相机声明的标准 0x100E；若未声明而声明 Nikon 0x9207，则尝试该扩展，参数为 0xFFFFFFFF、0（不要求自动对焦、写卡）。此分支来自开源接口约定，尚未在本项目的 Z50 无线实测。
- 拍后对象列表、JPG/NEF 成对出现的时序和传输完整性。
- 实际预览延迟及同步轮询对帧率的影响。监看优先时仍暂停整图传输，停止取景后补传。
