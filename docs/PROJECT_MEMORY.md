## 当前 0.4.0

用户反馈自动 ISO 不同步，要求监看改到底部统一导航、左右滑动、顶部可隐藏直方图工具栏和 + 菜单；JPG 内手动传 NEF；相册按文件夹分相机/手机导入/已接收/垃圾桶，支持单张/批量恢复及永久删除。

已实现 CameraIso：按相机公布读取 D054 自动开关、D0B5 只读感光度控制值，AUTO 显示控制值或 —，不冒用标准500F设定值。没有 Z50 真机确认。未使用 D16A 推断开关（开源 Z7 记录中该值可始终1，不能与D054等同）。

根页面 HorizontalPager 参数→监看→相册→设置，底部 Material 导航；监看遵循此前要求不重复放监看按钮。顶部直方图/网格/监看工具和 + 更多，可持久隐藏工具栏/底部导航。root BackHandler 历史栈，Gallery active 标志防止预加载页拦截返回。

相册四个固定分类文件夹，无自定义命名。相机按Storage/Parent层级查询 ObjectHandles 与 ObjectInfo，只显示目录/JPG。GetThumb预览、GetObject原图临时缓存、单张JPG保存、配对NEF手动下载；读取目录与手动传输先暂停监看。CameraEntry带会话token防断开重连错用对象，下载前核对元数据。新导入 JPG 来源记录存独立SharedPreferences，相机串号缺失则用本次token，重连后改从相机相册选。旧图/手机导入图按名称+字节大小唯一匹配，需用户确认；NEF只在同存储同父目录同名匹配，手动操作不受自动NEF开关限制，已在手机的同一NEF不重复下载。

手机导入OpenMultipleDocuments，复制JPG到Pictures/Nikonect/Phone并保留外部原片；导入进度/重复任务保护。垃圾桶R+用IS_TRASHED/DATE_EXPIRES，含垃圾桶查询；Q用Pictures/Nikonect/Trash，恢复原分类。永久删除只允许本应用拥有且当前已在垃圾桶的JPG并确认，不触碰独立NEF/卡片原片。分批操作失败可部分成功并报告数量。

版本0.4.0/code5，构建assembleDebug成功。当前没有新建/运行测试套件，不能沿用0.2.1的22项通过记录；本轮未对用户照片执行删除实验。完整限制和操作见RELEASE_0.4.0.md，产物outputs版本化APK和源码包。

实现：参数以 0x1015 实际回读为准，约900ms/监看1800ms轮询，约5秒更新描述；调节前重读、写后确认，边界禁用、不回绕。相册跨分页多选、全选、ClipData 多 URI 分享、确认后删除自有本地 JPG；不删除相机原片或 NEF。监看取消侧栏，参数/模式/WB/电量叠加画面，未知值显示 —，点曝光参数调节；顶部只含参数/相册/设置，支持隐藏恢复。返回使用历史栈，可保存页面状态。

版本 0.3.0 / code4，同包名签名可升级。构建成功；本轮没有新建或运行测试套件，之前22项测试记录仅属于0.2.1，不能算0.3.0通过。模拟器可查布局，不能证明镜头范围、拨轮同步或无线协议硬件兼容。当前完整说明 RELEASE_0.3.0.md，最终产物见 outputs 的0.3.0 APK/源码。

## 历史 0.2.0

工作根目录 D:\Nikonect。用户要求在 Codex 直接开发独立 Android App，安卓 USB Host / OTG 直连第一代 Nikon Z50，实现手机监看、参数调节、拍摄后自动传图和本地相册。

上一版 0.1.0 已构建，用户反馈真机可用但取景延迟大。本次要求降低延迟、去掉纵向滚动大页面，将监看/参数/相册/设置分开。监看要全屏、参数侧栏、网格和直方图；相册只显示 JPG，NEF 可选下载；加入实用设置。

0.2.0：移除每帧固定 200ms；取帧与解码并行，Channel.CONFLATED 只保留最新待解码帧；复用 64KiB USB 缓冲，解码下采样+RGB_565。监看优先默认开启，取景时暂停卡片扫描/整文件下载，停止后补传，避免 USB 争用。实际从相机到屏幕的延迟未在本地真机实测，不能宣称具体改善数值；界面显示的是本机取帧到解码耗时。

四个固定页面已实现，监看支持横屏/沉浸/隐藏侧栏/画幅适配与裁切填满、五种网格选项、亮度直方图；独立参数控制；JPG 分页相册与查看/缩放/分享；持久设置页面。

JPG 存 Pictures/Nikonect，NEF 默认关闭，开启后存 Download/Nikonect/NEF。筛选在 GetObject 前进行；JPG 优先。相册只查询本应用拥有且已完成的 JPG。关闭 NEF 后跳过的旧文件不补传，当前传输事务完成后才应用新开关。

测试状态见 BUILD_STATUS.md。纯协议与策略测试共 14 项；新增 androidTest 专用媒体存储验证，使用明确标注的临时测试 JPG 和 NEF 字节，不是相机实拍。测试包不打进正式主 APK。

## 最新接续：0.2.1

用户报告 0.2.0 发现相机后连接失败，实际提示“USB 读取超时或相机断开”。已恢复 0.1.0 使用的单次 16 KiB 读取，保留缓冲复用和低延迟流水线。64KiB 读取是重点怀疑的回归差异，但本地没有 Z50，不能宣称真机根因已确认。

USB 事务数据流被拆到纯 Kotlin PtpStream，Android UsbPtpSession 仅做接口/端点/互斥适配。新增 SessionAlreadyOpen 明确响应后的关闭重开及 Busy 有限重试，连接日志可显示阶段和操作码。22 项 JVM 测试（14 原有 + 8 数据流回归）通过，静态检查无错误。硬件连接仍需用户复测。

用户要求主界面为参数页、使用 Material Design、适当图标代替文字、监看顶部直接切换页面。已使用 Material 3 组件、统一选中状态和矢量轮廓图标；参数是默认首页，监看顶部常驻四页导航。模拟器已验证默认页面与顶部按钮位置和切换。版本号 0.2.1 / versionCode 3，包名和 debug 签名不变，可覆盖安装。最新文件见 outputs/Nikonect-0.2.1-debug.apk 和同版本源码 zip。
