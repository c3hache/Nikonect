# 0.2.1 连接兼容修正与 Material 3 导航

## 用户反馈与判断

用户报告：0.1.0 真机可用，0.2.0 能发现相机但连接失败，错误为“USB 读取超时或相机断开”。对比发现主要 USB 读取变化是单次请求从 16 KiB 改成了 64 KiB。虽然 Android API 允许更大的请求，特定手机/相机组合的行为仍可能不同。本次恢复旧版请求尺寸；这是针对回归的兼容修正，没有在本地 Z50 硬件上确认根因。

## USB/PTP

- 每次 bulk IN 恢复 16 KiB，继续复用缓冲，保留完整报文与多余字节。
- 保留 0.2.0 的最新帧缓冲、解码并行、去除固定 200ms 和监看优先策略。
- 把纯 PTP 数据流引擎从 Android USB 适配器中分离，新增 8 项回归测试，模拟拒绝超过 16 KiB 读取的设备、短包/分片、合并容器、流式照片、短写入、超时和事务 ID 错乱。
- 仅当相机明确返回 SessionAlreadyOpen（0x201E）时，尝试关闭旧会话再重开；Busy 有限重试。不做设备重置，不发送新的 Nikon 未验证扩展。
- 连接状态记录阶段（USB 接口、GetDeviceInfo、OpenSession、曝光参数）和操作码；超时标记通道无效，避免继续使用错位数据。
- 已打开的会话与可选存储/参数初始化分开报告；USB 通道损坏仍会关闭连接，未支持的属性不再造成通用连接失败。

## 界面

采用 Jetpack Compose Material 3 组件、统一金色导航状态与自绘矢量轮廓图标（不依赖图标字体）。默认首页为参数页；返回键回到参数页。首页保存键独立版本化，避免升级时恢复旧版监看首页状态。

监看页顶部常驻参数/监看/相册/设置四个带图标的页面按钮；更多菜单只放旋转、隐藏侧栏和画幅适配等选项。刷新、参数增减、拍摄、取景开关、网格和直方图适当使用图标，并保留中文辅助说明。参数页点击连接状态文字可查看完整提示并导出诊断。

## 验证

22 项 JVM 测试通过；构建成功；Lint 0 errors。模拟器覆盖安装成功，已检查默认参数首页、顶部四页按钮及其位置、页面切换、横屏监看与图标布局，未发现崩溃。实际 Z50 USB 连接恢复情况仍需同一手机/相机复测。

安装时覆盖更新，保留相册与设置。首次复测建议先断开 USB，再连接。如果仍超时，点参数页状态提示读取完整阶段信息，或在设置/诊断导出日志，避免只得到通用超时文字。
